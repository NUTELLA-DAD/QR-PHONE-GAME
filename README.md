# Airship Crew - starter (milestones 1-2)
    npm install
    npm start
Open http://localhost:3000/host.html on the big screen. Phones must be on the same Wi-Fi and scan the QR.
Off-LAN / HTTPS testing: `ngrok http 3000`, then `PUBLIC_URL=https://xxxx.ngrok.app npm start`.
Use "Add 4 test bots" on the host to fill the ship to 16 without phones.
